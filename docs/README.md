# 项目文档约定

本工程功能总览见 [项目功能说明](project-features.md)，文末预留修订记录与下次修订草稿。以下目录约定用于 Agent 维护的目标项目交付文档。

Agent 会围绕交易或微服务模块维护以下 Markdown 文档：

- `requirements/product-requirements.md`：正式产品需求文档
- `architecture/overall-design.md`：总体设计
- `detailed-design/`：详细设计、接口、数据和模块设计
- `testing/unit-test-report.md`：单元测试报告
- `testing/regression-test-report.md`：受影响范围回归测试报告
- `changes/change-log.md`：详细变更记录

每次代码修改必须同步记录修改文件、原因、影响范围、测试结果和 Git 提交编号。
